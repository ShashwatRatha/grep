Problem Statement: ISRO — On-Device Visual Perception for Light-Weight Browser Agents (SIH26171)
Overview
The objective of this problem statement is to build an autonomous, privacy-focused web browser agent that navigates and interacts with complex web applications purely using computer vision and on-device deep learning. Unlike traditional web scrapers that inspect HTML DOM structures (which break on dynamic sites and bot-protection layers), this agent operates like a human user—capturing live viewport screenshots, visually perceiving interactable UI elements, and executing actions directly on target pixel coordinates.
Crucially, all model inference must run locally on the end-user’s device with minimal latency, eliminating reliance on expensive cloud vision APIs.
